- 실행에 필요한 파일은 모두 저장소에 있습니다: 실행 스크립트(`package.json`), 실행 도구(`tools/start-alekov.ps1`), 서버(`src/server.mjs`), 화면(`public/`), 학생 코드(`student/extension.mjs`), 설정 견본(`.env.example`). [코드 확인]
- 앱 서버는 자기 폴더를 기준으로 파일을 찾고, 실행 도구도 자기 위치의 상위 폴더를 앱 폴더로 씁니다. 그래서 특정 절대경로에 의존하지 않습니다. [코드 확인: `src/server.mjs`의 `fileURLToPath(new URL('../',import.meta.url))`, `tools/start-alekov.ps1`의 `Split-Path -Parent $PSScriptRoot`] [새 환경 실행으로 다른 경로에서 동작 확인]
- 비밀값은 저장소에 없습니다. `.env.example`에는 비밀 없는 값만 있고, 실제 `.env`는 만들지 않았습니다. [코드 확인] [새 환경 실행]
- 설명서의 `C:\Users\Administrator` 같은 경로는 이 PC의 예시이며 실행 조건이 아닙니다.

### 7-2. 보존하지 않는 것과 한계

- 학생 코드는 데이터를 저장하지 않습니다. 필터 선택과 조회 진행 상태는 브라우저 메모리에만 있고, 새로고침이나 재실행 뒤에는 초기화됩니다. [코드 확인: `student/extension.mjs`]
- 화면의 조회 결과(기록·판정·AI 설명·패키지 조회)는 서버에서 다시 받아 오는 값이며, 백업 대상이 아닙니다.
- 제공 서버가 따로 보관하는 정보(앱 AI 자격 보관함, 조치 기록 등)의 저장 위치와 보존 방식은 확인하지 않았습니다. [UNV] 이 정보는 복사해서 옮기지 않고, 새 환경에서는 화면의 연결 절차로 다시 연결합니다. [코드 확인: `docs/IMPLEMENTATION_CONTRACT.md`]
- 열쇠·토큰·개인 설정 파일은 저장소·백업·제출물에 넣지 않습니다.
- 백업은 GitHub 계정에 의존합니다. 저장소를 비공개로 바꾸면 21·22단계 제출 때 원문 전달 도구가 필요합니다. [코드 확인: 과제 화면 안내]
- 새 폴더 `Desktop\keshev-repro-22`는 확인용 복사본입니다. 지워도 원래 폴더와 GitHub 기록에는 영향이 없습니다.
