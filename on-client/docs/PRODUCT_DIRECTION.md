# 앱 방향과 핵심 기능 (마지막 총공세 1일차)

작성: S13ee · 작성일 2026-10-26 · 기준 커밋: `15a775516de2b46eee157385b318ddf142afecd5` (보안 Agent 22단계)

이 문서는 학생이 새로 작성한 기획 문서입니다. 1일차에는 코드를 바꾸지 않았습니다.

> **2026-10-28 갱신:** 앱 이름을 **PC Drift**(내 PC, 평소와 달라진 것을 알려드립니다)로 정했고, 2~4일차에 핵심 기능 3가지를 만들었습니다. 9장에서 정하지 않았던 기준은 `PC_DRIFT.md`에 정했고, 10장 일정은 과정 안내 변경(포장 없음)에 맞춰 고쳤습니다. 1~8장은 1일차 기록이라 그대로 둡니다.
이 문서의 화면 예시에 나오는 숫자와 시각은 모두 **설명용 예시 값**이며, 실제로 잰 값이 아닙니다.

## 1. 한 줄 정의

**평소와 달라진 것만, 근거와 함께, 할 일로 알려 주고, 확인한 일은 다시 귀찮게 하지 않는 개인 PC 보안 점검 앱**

## 2. 설계 원칙: 조용한 보안 앱

1. **결론 먼저.** 첫 화면 맨 위에는 "지금 할 일 N개"가 나옵니다. 할 일이 0개면 그것이 곧 결론이고, 바로 닫아도 됩니다.
2. **바뀐 것만 알린다.** 매번 같은 값을 다시 알리지 않습니다. 평소 범위를 벗어났거나 상태가 바뀐 것만 할 일이 됩니다.
3. **확인한 일은 다시 알리지 않는다.** 사용자가 「확인했음」을 누른 일은 조용히 기록으로 넘어갑니다. 값이 다시 바뀌면 그때 새로 알립니다.
4. **근거를 함께 보여 준다.** 할 일마다 이전 값 → 지금 값, 잰 시각, 출처를 붙입니다. 판단만 보여 주지 않습니다.
5. **모르는 것을 숨기지 않는다.** 읽지 못한 값은 0이나 예시 값으로 채우지 않고 "확인 불가 + 이유"로 보여 주며, 필요하면 "확인할 일"로 바꿔 줍니다.
6. **읽기만 한다.** 방화벽·보안 설정을 바꾸지 않습니다. 할 일은 사람이 직접 하도록 안내만 합니다. 관리자 권한이 필요한 방법은 쓰지 않습니다.
7. **스스로 귀찮게 하지 않는다.** 팝업, 반복 알림, 자동 재시도를 하지 않습니다. 다시 점검은 사용자가 직접 누릅니다.

## 4. 핵심 기능 3가지와 순서

| 순서 | 기능 | 내용 | 하는 날 |
|---|---|---|---|
| 1 | **지금 점검** | CPU·메모리·디스크(2일차), 네트워크·방화벽·Windows 경고·오류 건수(3일차)를 한 번에 읽음. 값마다 잰 시각·출처·단위, 못 읽으면 확인 불가와 이유. SDP 연결 상태는 PC 조회 결과와 따로 표시 | 2~3일차 |
| 2 | **평소와 비교** | 지난 점검을 모아 이 PC의 평소 범위를 만들고, 벗어난 값과 상태가 바뀐 항목(예: 켜짐 → 꺼짐)을 찾음 | 2~3일차 |
| 3 | **할 일과 확인 처리** | 바뀐 것과 확인 불가를 할 일 카드로 보여 주고, 「확인했음」으로 조용히 넘김. 점검과 변화는 시간순 기록으로 남김 | 4일차 |

기존 기능(계정·기록·AI 설명 등)은 앱에 그대로 남지만, 실제 연결이 없어 핵심 기능에서는 제외했습니다.

## 5. 한 번 점검할 때의 흐름

| 단계 | 하는 일 | 예 (설명용 예시 값) |
|---|---|---|
| ① 점검 | 값을 읽고 잰 시각·출처·단위를 붙임 | 메모리 54% · 10:12 |
| ② 평소와 비교 | 평소 범위와 비교 | 메모리 평소 45~60% → 지금 88% |
| ③ 상태 변화 | 상태가 바뀐 항목을 찾음 | 공용 방화벽 켜짐 → 꺼짐 |
| ④ 할 일 | 바뀐 것·확인 불가를 할 일로 | "디스크를 읽지 못함 → 권한 확인 후 다시 점검" |
| ⑤ 확인 처리 | 「확인했음」을 누르면 같은 일로 다시 알리지 않음. 값이 또 바뀌면 다시 알림 | |
| ⑥ 기록 | 점검·변화·확인을 시간순으로 남김 | 10/27 09:12 발견 → 09:30 확인함 |

## 7. 다른 결과물과 다른 점

- 2·3일차 값(CPU·메모리·디스크·네트워크·방화벽·기록)은 모두가 만드는 공통 재료입니다. 이 앱은 그 값을 숫자로 나열하지 않고 **판단과 할 일의 근거**로 씁니다.
- 고정 기준(예: 80% 이상) 대신 **이 PC의 평소 범위**와 비교합니다. 처음에는 "평소 값 모으는 중(n/5회)"으로 정직하게 표시합니다.
- **확인 처리**로 같은 경고를 반복하지 않습니다.
- **확인 불가도 할 일**이 될 수 있습니다.

## 8. 확인해야 할 조건과 위험
